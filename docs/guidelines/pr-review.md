# PR Review

Verdict: **PASS / PASS WITH COMMENTS / BLOCK**.  Severity: Blocker / Major / Minor / Suggestion.

- Trace each acceptance criterion → the test that proves it.
- Checklist: correctness · security (no secrets, all data stays client-side) · error handling · tests · docs.
- Findings format: `[Severity] path:line — issue — suggested fix`.
- Reviewer returns findings only; does not edit.
