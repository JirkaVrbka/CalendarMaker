# Design Proposals

Write a proposal before: a new feature module, a cross-cutting change, a change to the saved-project
data model/schema, or a change to the PDF-export pipeline.

## Format

- **Problem statement**
- **Proposed solution** (with a Mermaid diagram)
- **Alternatives considered**
- **Impact assessment** (performance, print fidelity, IndexedDB migration/blast radius)
- **Open questions**
- **Acceptance criteria**
